# Transfer Scam Football

A football bluffing game: spot the fake club hidden among every real club from a footballer's career.

## Game modes

- **Single-player:** the game supplies a fake club; guess it and reveal the real career.
- **Private multiplayer:** two players construct believable fake careers for each other, then try to spot the scams.
- **Ranked multiplayer:** matchmaking, Elo ratings, and a competitive ladder.

Builders can type a real club or choose from five suggestions. Real clubs count senior first-team competitive appearances, including loans; youth and reserve teams are excluded. The beta will be free.

## Start implementation

This repository currently contains the complete planning and implementation handoff. Application code has not been implemented yet.

1. Read [CLAUDE.md](CLAUDE.md).
2. Follow the [complete implementation brief](docs/implementation-brief.md), including its ordered milestones and acceptance checks.
3. Consult the [product specification](docs/product-specification.md) for product context and research.

Build the application at the repository root. Begin locally with sourced football content and single-player, then private multiplayer, then accounts, ranked matchmaking and the ladder. The full local MVP is the target.

Do not invent football career records or treat incomplete data as evidence that a club is fake. Paid infrastructure and public deployment are separate from the initial implementation.
